HTML 代碼下載器

HTML Code Downloader

使用指南

How to Use

  1. 1

    用 AI 生成 HTML 程式碼，全選並複製

    Ask Gemini / ChatGPT to generate an HTML app. Select all the code and copy it.

  2. 2

    將程式碼貼入上方的文字框

    Paste the code into the text box above.

  3. 3

    點擊「下載 myapp.html」

    Click the download button. The file myapp.html will be saved to your Downloads folder.

  4. 4

    在下載資料夾找到 myapp.html，雙擊執行

    Locate myapp.html in your Downloads folder and double-click to open in your browser.

為甚麼不直接「另存為」.html？

Windows 預設隱藏副檔名。在記事本選「另存為」時，很容易儲存成 myapp.html.txt，雙擊只會打開記事本而非瀏覽器。此工具強制下載正確的 .html 副檔名。

Windows hides file extensions by default. "Save As" from Notepad often produces myapp.html.txt, which opens in Notepad instead of a browser. This tool forces the correct .html extension.

程式碼會上傳到伺服器嗎？

不會。整個過程完全在你的瀏覽器本地進行，程式碼不會離開你的電腦。

No. Everything happens locally in your browser. Your code never leaves your computer.
