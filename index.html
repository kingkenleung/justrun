使用教學

How to Use — Step by Step

情境 A · Case A 我想在自己電腦上執行 · Run on your own computer
  1. 1

    在 Gemini / ChatGPT 生成 HTML 程式碼

    Ask Gemini or any AI to generate an HTML app for you. Copy the entire code block.

  2. 2

    前往「HTML 代碼下載器」，貼上程式碼

    Go to the HTML Code Downloader tool and paste the code in the text box.

  3. 3

    點擊「下載」，取得 myapp.html 檔案

    Click the download button. A properly named myapp.html file will be saved to your computer.

  4. 4

    雙擊檔案，即可在瀏覽器執行

    Double-click the downloaded file to open it in your browser. Done!

為甚麼不直接儲存為 .html？ Windows 預設隱藏副檔名，直接「另存為」容易儲存成 myapp.html.txt，導致無法直接執行。此工具強制設定正確的 .html 副檔名。
Windows hides file extensions by default. Saving via "Save As" often creates myapp.html.txt instead. This tool forces the correct extension.
情境 B · Case B 我想即時分享給別人 · Share with others instantly
  1. 1

    在 Gemini / ChatGPT 生成 HTML 程式碼

    Generate your HTML app with AI, copy the full code.

  2. 2

    前往「即時分享工具」，貼上程式碼並點擊「開始託管」

    Go to the Live App Sharing tool, paste the code, and click "Start Hosting".

  3. 3

    系統自動產生分享連結和 QR Code

    A shareable URL and QR Code are generated automatically. No account or login needed.

  4. 4

    將連結或 QR Code 分享給朋友，他們掃碼即用

    Share the link or QR Code. Anyone can scan to run your app directly in their browser.

注意：你的瀏覽器頁面必須保持開啟，朋友才能連線。關閉後連結即失效。這是點對點（P2P）技術，你的電腦就是伺服器。
Your browser tab must stay open while others are connecting. The link expires when you close the tab. Your computer acts as the server via WebRTC P2P.

常見問題

FAQ

我需要安裝任何東西嗎？Do I need to install anything?

不需要。所有工具都在瀏覽器中運行，無需安裝任何軟件。
No. Everything runs in the browser. Nothing to install.

分享工具支援幾多人同時連線？How many people can connect at once?

理論上沒有上限，但由於所有連線都要經過你的電腦，太多人同時連線可能會較慢。適合課堂展示或小組分享。
Technically unlimited, but performance may degrade with many simultaneous connections since your computer handles each one. Best for classroom demos or small group sharing.

為甚麼朋友連不上？Why can't my friend connect?

常見原因：① 你的主機頁面已關閉 ② 學校或公司網絡封鎖了 WebRTC。試試讓朋友使用手機行動網絡（4G/5G）連線。
Common causes: ① Host tab was closed ② School/corporate network blocks WebRTC. Ask your friend to try with mobile data (4G/5G).

我的程式碼會上傳到伺服器嗎？Is my code uploaded to a server?

不會。所有程式碼只存在你的瀏覽器記憶體中，直接透過 P2P 傳輸給對方，不經過任何第三方伺服器儲存。
No. Your code lives only in your browser's memory and is sent directly peer-to-peer. It is never stored on any server.
