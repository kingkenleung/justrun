使用指南

How to Use

主機端（你）· Host (You)

  1. 1

    用 AI 生成 HTML 程式碼，全選並複製

    Ask Gemini / ChatGPT to generate an HTML app. Copy the full code.

  2. 2

    將程式碼貼入文字框，點擊「開始託管」

    Paste into the text box above, then click "Start Hosting".

  3. 3

    複製連結或讓朋友掃描 QR Code，保持此頁面開啟

    Share the link or QR Code. Keep this tab open the entire time.

用戶端（朋友）· Client (Your friends)

  1. 1

    打開分享連結或掃描 QR Code

    Open the shared link or scan the QR Code with any smartphone.

  2. 2

    等待連線完成，應用即自動載入

    Wait a few seconds for the P2P connection. The app loads automatically.

注意事項 · Important Notes

  • 主機頁面必須保持開啟。關閉後連結即失效。· Host tab must stay open; link expires when closed.
  • 連線超時？試用手機 4G/5G 網絡繞過學校防火牆。· Connection timeout? Try mobile data to bypass school firewall/NAT.
  • 程式碼不經任何伺服器儲存，直接 P2P 傳輸。· Code is sent peer-to-peer and never stored on any server.
  • 更新程式碼後再按「開始託管」，新連線用戶將看到最新版。· Update code and click the button again; new visitors will see the latest version.
